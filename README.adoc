== Features
	- Customizable Columns, Rows, Gaps, & Margin
	- Attach Gridt to window or an html element
	- Gridt stays open on hot reload
	- Adjustable line color, stroke width, & quick toggle keybinding

== Getting Started

=== Installation

Gridt is available for download on addons.mozilla.org (AMO)

https://addons.mozilla.org/en-US/firefox/addon/gridt

Gridt is now available for download on the Chrome Web Store

https://chromewebstore.google.com/detail/gijangdmilikehdjjipfhjbehcmajkpe

=== Build from source

```
gh repo clone gavink97/gridt .
cd gridt
npm install
make eb
make build
```
